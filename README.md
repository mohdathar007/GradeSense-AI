# GradeSense AI 🎬🎨

**GradeSense AI** is an intelligent color grading assistant designed to bridge the gap between creative vision and technical execution. Whether you want to translate an emotional description into a grade or match the look of a reference image, GradeSense provides professional-grade tools to achieve your vision.

## 🚀 Key Features

### 1. Emotion-to-Grade Engine 🧠
Translate natural language prompts into cinematic looks.
*   **Input**: Upload your footage and describe the mood (e.g., *"Warm 70s vintage look with soft contrast"*).
*   **AI Analysis**: The engine interprets your prompt to determine optimal Lift, Gamma, Gain, and Saturation offsets.
*   **Output**: Generates a downloadable **3D LUT (.cube)** and a predicted color palette.
*   **Insight**: Provides an "AI Consultant" explanation for *why* specific grading choices were made.

### 2. Reference Mirror 🪞
Match the color DNA of any reference image to your footage.
*   **Dual Input**: Upload your source shot and a reference image (the "look" you want).
*   **Smart Matching**: Uses advanced histogram matching and LAB color space processing to align the look.
*   **Visualization**: Side-by-side "Before & After" comparison slider.
*   **Metrics**: View technical match accuracy (PSNR) and structure retention scores.
*   **Export**: Generate a "Match Look" LUT to apply to your video editor (DaVinci Resolve, Premiere Pro, etc.).

### 3. Professional Scopes & Tools 📊
*   **Real-time Waveforms & Histograms**: Monitor your signal integrity.
*   **Palette Extraction**: Visualize dominant colors and tonal shifts.
*   **Glassmorphism UI**: A sleek, dark-mode interface designed for creative focus.

## 🛠️ Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/mohdathar007/GradeSense-AI.git
    cd GradeSense-AI
    ```

2.  **Create a virtual environment (optional but recommended)**:
    ```bash
    python -m venv venv
    # Windows
    .\venv\Scripts\activate
    # Mac/Linux
    source venv/bin/activate
    ```

3.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

##  ▶️ Usage

Run the web application using Streamlit:

```bash
python -m streamlit run app.py
```

The application will open automatically in your default web browser (usually at `http://localhost:8501`).

## 📦 Dependencies

*   `streamlit` - Web framework
*   `opencv-python-headless` - Image processing
*   `numpy` - Numerical operations
*   `scikit-image` - Color science utilities
*   `streamlit-image-comparison` - UI components
